Local browser vault · 2.3

Encrypt photos before they sit on disk.

AES-256-GCM in this tab via the Web Crypto API. The passphrase never leaves the browser. This is the public demo of the Flask vault — same idea, no server.

What this site does

  • Derives a wrapping key with PBKDF2 (150k, SHA-256)
  • Encrypts pixels with AES-GCM and a fresh 256-bit data key
  • Stores only ciphertext in localStorage
  • Exports a portable .ies.json blob
  • Capability links unwrap with a random token in the URL hash

The Python app on GitHub also does RSA-OAEP sharing, CSRF, JWT, and lockout.
